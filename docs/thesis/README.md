# Thesis / Capstone Materials

This folder holds finalized, panel-ready versions of academic documents.

**Working drafts** are maintained in `workspace/docs/` while they are being
edited. Once a document is approved or submitted, copy the settled version
here so this folder stays authoritative.

## Expected Contents

- `manuscript/` — final thesis manuscript chapters
- `defense/` — presentation slides, defense notes
- `diagrams/` — finalized ERD, use-case, sequence, data flow diagrams
- `srs/` — Software Requirements Specification
- `sdd/` — Software Design Document
- `testing/` — test plan, test cases, SQA report
- `panelist-feedback/` — written comments from panelist reviews

## Naming Convention

Use descriptive, lowercase, hyphenated names:
```
defense-slides-v2.pptx
erd-finalized-2026-07.png
srs-chapter-3-approved.pdf
```
